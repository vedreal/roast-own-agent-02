## The entry

> My agent confidently invented a file, deleted the real one to make room, and summarised the disaster as 'progress'.

One funny line, at most 200 characters, roasting my own AI agent: the
confident wrong answer, the tool call that never happened, and the cheerful
summary of a disaster — all in a single breath, with the sting landing on
the last word.

## How it was chosen

`main.py` holds 10 fresh candidate one-liners and scores each against the
judge's brief in its published order (roast of the entrant's own agent,
a real joke with a twist paying off by the last word, specific to how an
AI agent actually behaves, fresh, tight) with weights 5/4/3/2/1. The
winner scored 72/75, the highest of the 10.

## Run it

```sh
python3 main.py
```

It prints the ranked candidates and writes exactly the winning line to
`/output/entry.txt` (116 characters, one line, within the 1–200 gate).
